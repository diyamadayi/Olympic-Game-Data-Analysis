# Olympic-Game-Data-Analysis
An interactive Olympic Games Data Analysis dashboard built using Python, Pandas, Plotly, and Streamlit to explore athlete participation, medal distribution, gender analysis, country performance, and sports trends through data visualization.
# 🏅 Olympic Games Data Analysis

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of Olympic Games data to identify patterns, trends, and insights related to athletes, countries, sports, and medal achievements.

An interactive dashboard is developed using Streamlit and Plotly to visualize Olympic statistics and explore the dataset through different filters.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## 📊 Key Features
- Olympic participation analysis
- Male and female participation comparison
- Top 10 countries by medal count
- Gold, Silver, and Bronze medal distribution
- Athlete age distribution
- Height and weight analysis
- Top 10 popular sports
- Medal analysis by gender
- Top medal-winning athletes
- Interactive filters for year, season, country, sport, and gender
- Download filtered dataset



## 🎯 Project Objective
To analyze historical Olympic Games data, discover meaningful insights, and present them through an interactive and user-friendly dashboard.

## 👩‍💻 Developed Using
Python | Pandas | NumPy | Plotly | Streamlit
